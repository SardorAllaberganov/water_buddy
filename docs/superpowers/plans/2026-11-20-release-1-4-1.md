**Goal:** Make 1.4.1 ready to upload. #162 is fixed, the rating is asked on the first goal day, the store
text is rewritten for search in en-US with new en-GB and Russian listings, two new shots join the set, and the
build is 1.4.1 (7), gated and archived.

`amount(shown:format:otherwise:)` that `PremiumStore` uses for `Plan.amount`. Second, `DataManager.reviewStreak`
goes from 3 to 1, with its rule sentence and the privacy policy changed first. Everything else is text,
tooling and pictures in no build target. Each language's store fields go into one file per field, checked by a
new `Tools/VerifyListing.sh`. Two shots are captured on the pair `Tools/CapturePairScreenshots.sh` makes,
arranged with the simulator tool, then framed by `Tools/StoreScreenshots.html`.

**Tech Stack:** Swift (Foundation's `Decimal.FormatStyle.Currency`, StoreKit 2), swift-testing,
`project.pbxproj`, Markdown and plain text, one static HTML page, bash and Python 3 in `Tools/`, `sips`,
headless Chrome, the iOS Simulator tool.

**Spec:** `docs/superpowers/specs/2026-11-20-release-1-4-1-design.md`, approved by the owner ("Yes",
2026-11-20), with its rulings R1–R4 and decisions D1–D11.

## Global Constraints

- App behaviour changes in two places only: `Plan.amount`'s source (spec §3) and `reviewStreak` (spec §4).
  Logging is never paid for; nothing about Premium is stored.
- `PremiumAccess.swift` keeps `import Foundation` alone; `StoreKit` is imported in `PremiumStore.swift` and
  `HomeView.swift` only (rule `70-privacy`). `PremiumAccessTests` stays off the main actor (rule `43-concurrency`).
- `MARKETING_VERSION = 1.4.1` and `CURRENT_PROJECT_VERSION = 7`, each on 14 sites.
- **Never commit.** Stage by explicit path and stop for the owner's `/commit` (rule `90-git`). Never stage
  `.claude/settings.json`, either watch scheme or the three catalogues the tree carries unstaged; never
  `git stash pop`. The rule sentence of Task 5 is typed into `.claude/rules/70-privacy.md` and left
  **unstaged** for the owner.
- **Change a file only with Write (new or whole) or Edit (a change).** No `sed -i`, no `cp`, no `rm -rf`, no
  script that writes into the tree. Delete a tracked file with `git rm`. A scratch folder is new each time
  (`…-$(date +%H%M%S)`), never emptied (lessons 2026-10-09, 2026-10-31).
- `xcodebuild` in the foreground, **one per call**: `build-for-testing` once, then `test-without-building`,
  each under 600 s, with `-parallel-testing-enabled NO -test-timeouts-enabled YES`; a run of one test or one
  suite adds `-collect-test-diagnostics never`; UI chunks are at most seven tests (lessons 2026-10-24,
  2026-10-25, 2026-11-04). `OS=27.0` pinned; the UI suite again on `OS=26.5`. Gates run on a
  `git checkout-index` copy of the index.
- **One exception, argued:** `bash Tools/CapturePairScreenshots.sh setup` runs one `xcodebuild test` that took
  about 30 minutes on 2026-10-26, past the 600 s foreground limit. It runs in the background, and nothing
  rests on it until its whole log has been read (`** TEST SUCCEEDED **`, `Executed 1 test, with 0 failures`).
- **Simulators are shared with other projects' sessions.** Before anything runs `xcrun simctl shutdown all` —
  the gate, `setup` — list them (`ListAgents`), ask the ones that use simulators, and wait for their word.
  Tell them when the run is done, **before** any staging, commit or report (lesson 2026-11-06).
- No ad-hoc script writes `group.sardor.WaterBuddy` or `UserDefaults.standard`; `defaults write` is denied.
- No person's name, email or bundle identifier goes into a web request. `AppStore/research/` carries no
  review text and no reviewer's name.
- Store text files end **without** a newline; `bash Tools/VerifyListing.sh` is the count of record.
- Every new prose text (promotional text, What's New, the Russian description, the two headlines) passes
  through the owner's `humanize` skill before it is final. Name, subtitle and keywords do not: they are the
  research's words.
- A headline names only what its screen shows: no *AI*, no *Apple Intelligence*, no price, no *Free*, no
  claim about a locked phone (framing spec F5–F6; spec §6.2).
- A denied tool call is a stop sign: report it and stop (`CLAUDE.md`).

## Review Focus

1. **A storefront whose shown price does not read back.** The parse must leave StoreKit's own figure, never
   crash or invent a saving — Task 3's `aShownPriceThatCannotBeReadFallsBack`.
2. **An *Undo* inside the rating's pause.** The first goal day's pour, undone before the pause ends, must
   ask nothing — Task 5 Step 7, by hand on a simulator.
3. **A widget placed by a tap that pours.** Arranging the Home Screen or the Lock Screen must not log water:
   every figure in the scratch picture reads 65 % and 1,300 ml before each `shoot`, or `setup` runs again —
   Task 11 Steps 5 and 7.
4. **A text that fits only before `humanize`.** A rewrite lengthens a field past Apple's limit or leaves a
   trailing newline — Task 10 runs `VerifyListing.sh` after the pass, not before.
5. **A Russian sentence the build does not do** — Siri's Russian phrases, the control's Russian title, the
   reminders' hours, the language the insights are worded in — Task 10 Step 7 reads each claim against
   the catalogue or code it names.

    /// Russian, Uzbek, Kazakh, German, Brazilian, Turkish and Indonesian among them — it hands back the
    /// price's whole number, 19 for $19.99. Measured in the local StoreKit configuration (2026-10-21) and
    /// against the App Store sandbox (2026-11-13); the device's region is the cause. `displayPrice`, read
    /// back with the product's own `priceFormatStyle`, keeps the fraction, so the yearly's saving is the

        guard let read = try? format.parseStrategy.parse(shown), read > 0 else { return price }
        return read
    }

### Task 9: `Tools/VerifyListing.sh`

**Files:** Create: `Tools/VerifyListing.sh`

**Interfaces:**
- Produces: `bash Tools/VerifyListing.sh` — exit 0 when every field file in `AppStore/`, `AppStore/en-GB/` and
  `AppStore/ru/` is inside its limit, ends without a newline, is not empty, breaks no keyword rule, every en-US
  file equals its `README.md` block, and every en-GB file but the keywords equals en-US's; exit 1 otherwise,
  naming each breach.

- [ ] **Step 1: Write the script**

```bash
#!/bin/bash
#
#  Tools/VerifyListing.sh — every App Store text field, counted against Apple's limits and the ASO playbook's
#  keyword rules, for each listing language (spec docs/superpowers/specs/2026-11-20-release-1-4-1-design.md
#  §5, D7).
#
#  Run:  bash Tools/VerifyListing.sh
#
#  Reads  AppStore/        the en-US fields, one file each, and README.md's App Store Connect blocks
#         AppStore/en-GB/  the English (U.K.) listing — the en-US text but for its keywords
#         AppStore/ru/     the Russian listing
#  Exits 1 on a missing or empty file, a trailing newline, a field over its limit, a keyword that breaks a
#  rule, an en-US file unlike its README block, or an en-GB field unlike en-US's. Prints every count either
#  way. Reads only.
#
#  Invoked through `bash`, as the other scripts here are: `chmod` is on this project's deny list. Lives in
#  Tools/, in no build target (rule 15-project).
#
set -uo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
exec python3 -I - "$ROOT" <<'PY'
import re
import sys

root = sys.argv[1]
# Apple's limits, as the owner's aso skill records them (references/apple-rules.md, read 2026-11-20):
# characters, but bytes for the keyword field and the review notes.
LIMITS = {
    "name.txt": (30, "chars"),
    "subtitle.txt": (30, "chars"),
    "keywords.txt": (100, "bytes"),
    "promotional-text.txt": (170, "chars"),
    "whats-new.txt": (4000, "chars"),
    "description.txt": (4000, "chars"),
    "review-notes.txt": (4000, "bytes"),
}
LISTINGS = [("en-US", "AppStore"), ("en-GB", "AppStore/en-GB"), ("ru", "AppStore/ru")]
failures = []
texts = {}


def words(text):
    return {w for w in re.split(r"[^\w]+", text.lower()) if w}


for label, folder in LISTINGS:
    print(f"== {label}  ({folder}/)")
    fields = texts.setdefault(label, {})
    for name, (limit, unit) in LIMITS.items():
        if name == "review-notes.txt" and label != "en-US":
            continue
        try:
            text = open(f"{root}/{folder}/{name}", encoding="utf-8").read()
        except FileNotFoundError:
            failures.append(f"{label}: {name} is missing")
            print(f"  {name:22} MISSING")
            continue
        fields[name] = text
        size = len(text.encode("utf-8")) if unit == "bytes" else len(text)
        flags = [flag for flag, bad in (("OVER", size > limit), ("ends with a newline", text.endswith("\n")),
                                         ("empty", not text.strip())) if bad]
        failures += [f"{label}: {name} {flag}" for flag in flags]
        print(f"  {name:22} {size:5} / {limit} {unit}  {', '.join(flags) or 'ok'}")
    keywords = fields.get("keywords.txt")
    if keywords is not None:
        terms = keywords.split(",")
        taken = words(fields.get("name.txt", "")) | words(fields.get("subtitle.txt", ""))
        problems = ["a space"] if " " in keywords else []
        for term in terms:
            if len(term) <= 2:
                problems.append(f"'{term}' is two characters or fewer")
            if term in taken or term.rstrip("s") in taken or f"{term}s" in taken:
                problems.append(f"'{term}' repeats the name or subtitle")
            if term in ("apple", "iphone"):
                problems.append(f"'{term}' is Apple's mark")
        if len(set(terms)) != len(terms):
            problems.append("a duplicate")
        failures += [f"{label}: keywords: {problem}" for problem in problems]
        print("  keyword rules:", "; ".join(problems) or "pass")

# en-US against README.md's App Store Connect section, the master copy (spec §5.4).
readme = open(f"{root}/README.md", encoding="utf-8").read()
section = readme[readme.index("# App Store Connect"):]


def block_after(heading):
    start = section.index(heading)
    opening = section.index("```\n", start) + 4
    return section[opening:section.index("\n```", opening)]


def row(field):
    match = re.search(rf"\| \*\*{field}\*\* \(≤30\) \| `([^`]*)`", section)
    return match.group(1) if match else None


masters = {
    "name.txt": row("Name"),
    "subtitle.txt": row("Subtitle"),
    "promotional-text.txt": block_after("## Promotional text"),
    "keywords.txt": block_after("## Keywords"),
    "description.txt": block_after("## Description"),
    "whats-new.txt": block_after("## What's New"),
    "review-notes.txt": block_after("## Review notes"),
}
print("== en-US against README.md")
for name, master in masters.items():
    if name in texts["en-US"]:
        same = texts["en-US"][name] == master
        failures += [] if same else [f"en-US: {name} differs from README.md"]
        print(f"  {name:22} {'same' if same else 'DIFFERS'}")

# en-GB is en-US's text but for the keywords (spec §5.2).
print("== en-GB against en-US")
for name, text in texts["en-GB"].items():
    if name != "keywords.txt" and name in texts["en-US"]:
        same = text == texts["en-US"][name]
        failures += [] if same else [f"en-GB: {name} differs from en-US"]
        print(f"  {name:22} {'same' if same else 'DIFFERS'}")

print()
if failures:
    print(f"{len(failures)} problem(s):")
    print("\n".join(f"  - {failure}" for failure in failures))
    sys.exit(1)
print("Every field is inside its limit, and every rule holds.")
PY
```
