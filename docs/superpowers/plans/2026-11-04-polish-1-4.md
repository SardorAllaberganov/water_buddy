# Release 1.4, polished before the capture — Implementation Plan

> **For agentic workers:** this project runs every task in the main loop — there is no implementation subagent
> (`CLAUDE.md`, *Implementation — one loop, tests first*). Use superpowers:executing-plans. Steps use checkbox
> (`- [ ]`) syntax for tracking.

**Goal:** close known issues #221–#224 on `release/1.4` before phase 2's capture: one test made to compare what it
claims, a purchase's laps in the spec's 1.9 s, Settings' Premium lap timed by the slide's end, and #224 retired on
its recordings.

**Architecture:** #221 changes only its test. #222 gives `PremiumRim` one function for how long its laps take. #223
moves the moment a tab's page has landed into `PageTurn`, the pure value that already knows when a slide ends, and
hands it down through one environment value; Settings' card keeps its own lap flag. #224 is records only.

**Tech Stack:** Swift 5 mode, SwiftUI, swift-testing, XCTest, Xcode 27.0; simulators iOS 27.0, 26.5, 18.6.

**Spec:** `docs/superpowers/specs/2026-11-04-polish-1-4-design.md` (approved, "ok", 2026-11-04).

## Global Constraints

- Work on `release/1.4`. **Never commit:** stage with explicit paths and stop; the owner runs `/commit` (rule `90-git`).
- Tests first: write the test, run it and **see it fail**, then implement, then green (rule `85-testing`). Never narrow
  an assertion to pass.
- Edits through **Edit**, new files through **Write** — never a Python or `sed` replace (`tasks/lessons.md`,
  2026-11-04). **One `xcodebuild` per call**, foreground, `-parallel-testing-enabled NO`; never a `for` loop or a
  script around it (2026-11-03). In zsh a built argument list is expanded `${=ARGS}` (2026-11-04).
- A UI chunk is **at most seven tests**, one chunk to a call; every alone or A/B run passes
  `-collect-test-diagnostics never` (2026-11-04).
- One simulator of mine at a time, shut down before the next boots. Other projects' booted simulators (*iPhone 16 Pro*,
  *OverlaneDrive 18.6*, *WareStack 18.6*) are left as they are — phase 1's ruling, carried over, no `simctl shutdown all`.
- Probes, delays and recordings live in a `git checkout-index` copy in the scratchpad, never in the tree.
- No new warning on any scheme, compared by file and message against a clean build of `ea67781`.
- Comments explain why, at the density of the file edited. No `TODO`. No bare `withAnimation`.

## Review Focus

1. **A page left before its slide ends** — Settings turned to, then Home tapped mid-slide: Settings' card must never
   run its lap on the page that is leaving. Pinned by `aPageLeftBeforeItsSlideEndsNeverLands` (Task 3).
2. **Reduce Motion** — no lap anywhere, and the card is drawn whole. `PremiumRim` already gates the light on
   `!reduceMotion`; Task 3's recording takes one turn under Reduce Motion to see nothing stuck lit.
3. **A purchase made from Settings' paywall** — the card turns into its held form with `lit` already up: no second
   lap and no light left standing. `theLightIsGoneBeforeItStartsAndWhenItEnds` pins the end state at zero; no new code.
4. **Every other rim keeps its pace** — the recap's, export's and Insights' one lap stay 1.5 s. Pinned by
   `duration(laps: 1) == lapDuration` (Task 2).
5. **The floor's system** — the whole phone unit suite on iOS 18.6, where #221 was its only failure, must pass
   (Task 4).

private struct PageHasLandedKey: EnvironmentKey {

        set { self[PageHasLandedKey.self] = newValue }

}
