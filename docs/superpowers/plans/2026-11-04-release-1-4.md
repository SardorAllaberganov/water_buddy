## Global Constraints

- Nothing in the app, the widget or the watch changes behaviour. `PRIVACY.md` and `Tools/PrivacyPolicy.html`
  do not change (spec §5, §11).
- `README.md`'s *App Store Connect* is the master. Each `AppStore/1.4/*.txt` equals its spec block byte for
  byte and ends **without** a newline.
- The limits: promotional text ≤ 170, keywords ≤ 100, description ≤ 4000, What's New ≤ 4000, review notes ≤
  4000. A count is Python's `len` of the file.
- The store text uses `-` for dashes, as the 1.4 text does. `README.md`'s own prose keeps its em dashes.
- `MARKETING_VERSION = 1.4` on 14 sites; `CURRENT_PROJECT_VERSION = 5` on 14 sites.
- **Never commit.** Stage by explicit path and stop for the owner's `/commit` (rule `90-git`). Never stage
  `.claude/settings.json`, either watch scheme or the three catalogues the tree carries unstaged, and never
  `git stash pop`.
- `xcodebuild` in the foreground, one simulator at a time, `xcrun simctl shutdown all` first,
  `-parallel-testing-enabled NO`, `OS=27.0` pinned (rule `85-testing`). Gates run on a
  `git checkout-index` copy of the index, because the working tree carries two unstaged schemes
  (`tasks/lessons.md`, 2026-10-21).
- No ad-hoc script writes `group.sardor.WaterBuddy` or `UserDefaults.standard`. The capture's fresh start
  uses a throwaway suite.
- The store capture runs only from the 8th of a month, between 1:45 PM and 11:45 PM
  (`AppStoreScreenshotUITests.earliestDay`).

## Review Focus

1. **A store sentence the build does not do.** A reviewer or a user reads the description and does not
   find it, especially *corrected or deleted there when you change it here* (Health) and *reminders only
   when you are behind*. Task 2 Step 5 reads each such sentence against the code it names.
2. **A paste that is not the text.** A trailing newline, or a README block that drifted from its `.txt`,
   reaches App Store Connect. Task 2's checker compares the spec, the README and the file, three ways.
3. **A tap that lands on the tab bar.** The two new shots tap rows near Settings' foot, under the floating
   bar (#209). Task 5 scrolls each row clear of the bar's whole frame before the tap.
4. **A build number missed on one site.** If the app's and an extension's `CFBundleVersion` disagree,
   App Store Connect warns or refuses. Task 6 reads all four built products.
5. **The support page in dark mode, at a phone's width, or fetching something.** Task 4 Step 4 opens it
   in both schemes at 390 pt and greps it for any outside request.

```python
#!/usr/bin/env python3
"""Holds 1.4's store text to the spec: each field's file, README.md's master block, the counts."""
import pathlib, re, sys

root = pathlib.Path(sys.argv[1])
spec = (root / 'docs/superpowers/specs/2026-11-04-release-1-4-design.md').read_text(encoding='utf-8')
section = spec.split('\n## 3. ', 1)[1].split('\n## 4. ', 1)[0]
blocks = re.findall(r'```\n(.*?)\n```', section, flags=re.S)
fields = [('promotional-text', 170), ('keywords', 100), ('description', 4000),
          ('whats-new', 4000), ('review-notes', 4000), ('iap-note', 4000)]
readme = (root / 'README.md').read_text(encoding='utf-8')
upload = (root / 'AppStore/1.4/README.md').read_text(encoding='utf-8')
iap = (root / 'AppStore/1.4/in-app-purchases.md').read_text(encoding='utf-8')
fails = 0

def check(ok, message):
    global fails
    print(('ok   ' if ok else 'FAIL ') + message)
    fails += not ok

check(len(blocks) == len(fields), f'the spec carries {len(blocks)} blocks in §3')
for (name, limit), want in zip(fields, blocks):
    n = len(want)
    check(n <= limit, f'{name}: {n}/{limit}')
    if name == 'iap-note':
        check('```\n' + want + '\n```' in iap, 'iap-note: in-app-purchases.md Step 6 carries it')
        check(f'({n} characters)' in iap, f'iap-note: Step 6 says {n} characters')
        check('```\n' + want + '\n```' in readme, 'iap-note: README.md carries the block')
        continue
    check('```\n' + want + '\n```' in readme, f'{name}: README.md carries the block')
    got = (root / 'AppStore/1.4' / f'{name}.txt').read_text(encoding='utf-8')
    check(got == want, f'{name}: {name}.txt equals the block, no trailing newline')
    if name != 'review-notes':
        check(f'**{n}/{limit}**' in readme, f'{name}: README.md heading says {n}/{limit}')
    check(f'{n} / {limit}' in upload, f'{name}: AppStore/1.4/README.md says {n} / {limit}')
for stale in ['it was never built', 'No Apple Health', '(build 4)', '**1.4 (4)**']:
    check(stale not in readme and stale not in upload, f'nothing says "{stale}"')
for bullet in ['- **Apple Health**, when the user turns it on', '- **The export file** leaves only']:
    check(bullet in readme, f'App Privacy carries "{bullet[4:30]}…"')
sys.exit(1 if fails else 0)
```
